## Ground rules (every slice)

1. **Speed first.** Off = zero cost: no pipeline built (create GPU objects
   lazily, never in `resumed`), no per-frame work, one bool check. On = bounded
   GPU cost; measure (jetty-bench / timing in jetty-shot). Idle stays 0% CPU: no
   continuous redraw except an explicit opt-in animation; bounded animations are
   an `Option<Instant>` that expires on the wall clock in `about_to_wait` and
   feed `main_pending` like `caret_anim`; one-off paints go through
   `request_main_paint` (`scripts/check-paint-choke.sh` enforces it). Clear every
   animation in both hide paths. Never animate glyph colors/positions through
   the grid (it defeats the per-row shaping cache, text.rs:31/71/86).
2. **Defaults keep today's look**, except: bug fixes, contrast fixes, built-in
   box/powerline/braille glyphs, inner padding, OSC 9;4 progress, tab
   finished/failed badges, color emoji.
3. **No desktop-environment-specific code.** The freedesktop settings portal
   (`org.freedesktop.portal.Settings`, via zbus — already in Cargo.lock through
   notify-rust) is a cross-desktop standard and allowed (kitty and WezTerm use
   it). No KWin/GNOME APIs, no compositor blur.
4. **Declined / not tonight:** ligatures, text blink, cursor blink, split panes,
   session restore, smooth pixel scrolling, hide (dismiss) animations, theme
   import from other formats, persistence/burn-in, new default key chords.
5. **Main window, detached windows and jetty-shot share the render paths** —
   every visual works in all three (`render_grid_scene` ~app.rs:13523 is shared;
   jetty-shot and jetty-bench keep their own copy of Pass 1 — update them too).
6. **Tests:** pure unit tests; every new WGSL gets a naga validation test and a
   uniform-layout test (pattern in crt.rs); tests never open windows, touch the
   clipboard or fire notifications; anything needing a GPU is `#[ignore]`.
7. **`crates/jetty-render/src/panel.rs` belongs to slice S only.** Other slices
   add config keys, palette commands and rendering; S builds the controls.
8. **Look at your work.** jetty-shot renders offscreen on the Intel iGPU
   (`JETTY_SHOT_OUT=<png>`; set `JETTY_CONFIG_DIR` to a scratch copy, never the
   real one) — add a `JETTY_SHOT_*` hook for every new visual. For interactive
   behavior use `scripts/nested-live.sh` (`DISPLAY_NUM=<your number>`; it runs
   your worktree's `target/release/jetty`, or `NESTED_BIN=target/debug/jetty`)
   with software Vulkan on an invisible X server. Check a dark AND a light theme
   (catppuccin_mocha + catppuccin_latte / solarized_light). Read the PNGs.
9. **Gate before reporting done:** `cargo build --workspace --all-targets`,
   `cargo test` (whole workspace; 1024 tests at the start), `cargo clippy
   --workspace --all-targets` with no new warnings (baseline 13 unique),
   `scripts/check-paint-choke.sh`, `cargo check --target aarch64-apple-darwin
   -p jetty-app`. Use `CARGO_BUILD_JOBS=4` (nine slices build at once).
10. **Never** touch the owner's running JeTTY (`/usr/bin/jetty`), `~/.config/jetty`,
    the real display `:0`, or any process you didn't start (`pkill` is
    forbidden — kill by PID). No `git push`. Commit on your branch; before the
    final report, `git rebase main` (other slices land there during the night),
    resolve conflicts, re-check your pixel math against whatever landed (padding
    from slice B changes the grid origin), re-run the gate.
