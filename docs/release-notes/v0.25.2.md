# JeTTY v0.25.2

**Prebuilt packages run on older distros again.** No code changes — this is a
build fix.

## The fix

The AppImage, `.deb` and tarball refused to start on anything older than
Ubuntu 24.04:

```
/lib/x86_64-linux-gnu/libc.so.6: version `GLIBC_2.39' not found
```

Releases were built on `ubuntu-latest` (24.04, glibc 2.39). There, Rust std
weak-links two optional functions (`pidfd_spawnp`, `pidfd_getpid`) with a
`GLIBC_2.39` version tag — and the loader enforces that tag even though the
functions are optional. The `.deb` also declared `libc6 (>= 2.39)`. The
[AppImage catalog](https://appimage.github.io)'s test, which runs on Ubuntu
22.04, caught it.

Releases are now built on Ubuntu 22.04, and the workflow refuses to publish a
binary that needs a newer glibc. All three packages run on **glibc 2.35+**:

| Distro | glibc | v0.25.1 | v0.25.2 |
|---|---|---|---|
| Ubuntu 24.04+ | 2.39+ | ✅ | ✅ |
| Debian 12 | 2.36 | ❌ | ✅ |
| Ubuntu 22.04 | 2.35 | ❌ | ✅ |

If you're already running v0.25.1 happily, there's nothing new here for you.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/bozdemir/JeTTY/main/install.sh | sh
```

Or a `.deb` / **AppImage** from the assets below (the installer verifies
`SHA256SUMS.txt`). Build from source: `cargo build --release`.
