# JeTTY v0.28.1

**The AppImage starts on minimal systems.**

JeTTY loads its X11, keyboard and cursor libraries at run time, so the
packaging tools never saw them: the AppImage carried none, and on a system
without `libxkbcommon-x11` — the AppImage catalog's test machine — it stopped
at once ("Library libxkbcommon-x11.so could not be loaded"). The AppImage now
carries libxkbcommon, libxkbcommon-x11, libXcursor and libXi (X11, xcb and
OpenGL/EGL stay the system's), and the `.deb` depends on everything JeTTY
loads. No change to JeTTY itself — everything in
[v0.28.0](https://github.com/bozdemir/JeTTY/releases/tag/v0.28.0) applies.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/bozdemir/JeTTY/main/install.sh | sh
```

Or a `.deb` / **AppImage** from the assets below (the installer verifies
`SHA256SUMS.txt`). Build from source: `cargo build --release`.
