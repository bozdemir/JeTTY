# JeTTY v0.29.1

**Fixes from a scan of the whole codebase: menus that behave, output that
can't freeze JeTTY, prompt marks that stay put, and GPU resets that no longer
take your shells with them.**

- **Menus hold the keyboard like native ones** (a 0.29.0 regression). Any key
  that isn't the menu's closes it and does its usual job, so typing after a
  stray Menu press no longer pastes at the first Space. Menus also close on
  focus loss, hide and tab switches, and nothing behind an open menu gets
  your wheel or clicks.
- **Program output can't freeze JeTTY or eat its memory any more:** Kitty
  image re-placements, sixel/PNG/zlib "bombs", gigantic window titles on the
  title stack and huge OSC 8 link ids are all bounded now.
- **Shell-integration marks stay put** with powerlevel10k: after resizes and
  font zooms, under a right prompt, and around editors that end inside a
  synchronized update (Neovim ≥ 0.10).
- **A GPU reset no longer closes JeTTY** and every shell (suspend/resume,
  driver resets), and the cursor trail survives it.
- **Bold stays on the grid** in fonts without a bold face (Ubuntu Mono,
  Ubuntu Sans Mono, Noto Mono).
- **Smaller fixes:** clicks in fzf's Ctrl+R while scrolled back, a double-click
  on "+" no longer starts a rename, the Settings scrollback cycler no longer
  wraps from 100k to 1k, a rejected `[keys]` binding keeps its default, X11
  keyboard grabs (a held media key, Alt+Tab) no longer auto-hide the window,
  dead key + Space types the accent on Wayland, and on macOS hiding returns
  the keyboard to your previous app, the Dock icon brings JeTTY back, and
  shells get a UTF-8 locale. `scripts/make-macos-app.sh` builds again (#7).

The full list is in the [CHANGELOG](https://github.com/bozdemir/JeTTY/blob/main/CHANGELOG.md).

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/bozdemir/JeTTY/main/install.sh | sh
```

Or a `.deb` / **AppImage** from the assets below (the installer verifies
`SHA256SUMS.txt`). Build from source: `cargo build --release`.
