# JeTTY v0.29.0

**Menus from the keyboard, and an AppImage that updates itself.**

- **Every menu works from the keyboard.** In the right-click menu, a tab's
  menu (and its Color list) and a detached window's menu, the arrows (or
  `Home` / `End`) move, `Enter` or `Space` picks, `→` / `←` open and leave a
  tab's Color list, and `Esc` closes.
- **The Menu key opens the right-click menu at the text cursor**
  (`[keys] context_menu`), above the prompt when there's no room below. It's
  also in the command palette as "Open context menu", for keyboards without a
  Menu key.
- **The AppImage updates in place.** It carries update information, and this
  release publishes `JeTTY-0.29.0-x86_64.AppImage.zsync` next to it, so
  [AppImageUpdate](https://github.com/AppImageCommunity/AppImageUpdate) (or
  AppImageLauncher) downloads only what changed.
- **A failed command's notification no longer sticks.** It was sent as
  "critical", which notification daemons keep on screen until dismissed (and
  which breaks through Do Not Disturb); it now expires like any other.

Everything in [v0.28.0](https://github.com/bozdemir/JeTTY/releases/tag/v0.28.0)
and [v0.28.1](https://github.com/bozdemir/JeTTY/releases/tag/v0.28.1) applies.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/bozdemir/JeTTY/main/install.sh | sh
```

Or a `.deb` / **AppImage** from the assets below (the installer verifies
`SHA256SUMS.txt`). Build from source: `cargo build --release`.
