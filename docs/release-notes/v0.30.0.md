# JeTTY v0.30.0

**The rest of the whole-codebase scan: Wayland that summons, a terminal that
stays quick while another tab floods, and about 170 smaller fixes across every
part of JeTTY.**

- **Wayland works.** F9 / `jetty --toggle` bring JeTTY back after a hide
  (hiding now closes the window while every tab keeps running), tiling
  compositors hide it too, paste reads what native Wayland apps copied, and
  docks show JeTTY's icon. `summon_hotkey = "none"` turns the built-in grab off
  so you can bind `jetty --toggle` yourself.
- **Typing stays instant while another tab floods:** keypress-to-frame drops
  from about 47 ms to about 3 ms; throughput is unchanged.
- **Search keeps up with streaming output** (a refresh at 100k lines: ~220 ms →
  0.2 ms), the match you jumped to stays current, and copy-mode / hint mode hold
  the view still while output arrives.
- **Text:** bold and italic reach NFD names and fallback glyphs, flags draw as
  one emoji, every glyph stays on its cell, and characters no installed font
  has no longer freeze the window.
- **Images** start at the cursor, keep their rows through resizes, fullscreen
  and font zoom, and survive `mpv --vo=kitty`; Kitty images ended by BEL work.
- **One overlay order:** help, search, hints, copy mode and the palette no
  longer open under each other; palette rows show their live shortcut, and
  "Help: keyboard shortcuts" is a palette search away.
- **Safer output:** control and bidi characters can't spoof titles or
  notifications, the link preview leads with the real host, hidden text is
  never run, and a `file://` link to another machine isn't opened locally.
- **Summon and windows:** a WM-minimized window stops rendering (X11), Dropdown
  docks below panels and the macOS menu bar, Center gets its size back after
  Dropdown, and `ssh -X` / a second X session start their own JeTTY.
- **Shell integration:** a new opt-in line that starts no process per shell
  (and works on macOS's bash 3.2); Ctrl+C interrupts a huge paste; auto-summon
  works with notifications off.

The full list is in the [CHANGELOG](https://github.com/bozdemir/JeTTY/blob/main/CHANGELOG.md).

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/bozdemir/JeTTY/main/install.sh | sh
```

Or a `.deb` / **AppImage** from the assets below (the installer verifies
`SHA256SUMS.txt`). Build from source: `cargo build --release`.

Every file carries a signed build provenance:
`gh attestation verify <file> --repo bozdemir/JeTTY`.
