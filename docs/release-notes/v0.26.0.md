# JeTTY v0.26.0

**The audit release.** A full review of the codebase turned up ~90 issues —
bugs, a few security holes, slow paths and missing basics. This release fixes
them. It is the biggest change to JeTTY since the first version, so the
behavior changes come first.

## Read this first — behavior changes

| What | Before | Now | Want the old way? |
|---|---|---|---|
| Plain **PageUp / PageDown** | scrolled JeTTY's scrollback | go to the program (zsh history, fzf, less…) | `[keys]` `scroll_page_up = ["Shift+PageUp", "PageUp"]` (and `_down`) |
| **Shift+PageUp / PageDown** | scrolled | still scroll — on every screen | — |
| **Transparency** | Ctrl+Shift+= / Ctrl+Shift+- | **Ctrl+Alt+= / Ctrl+Alt+-** | `[keys]` `opacity_up` / `opacity_down` |
| **Ctrl++** (zoom in) | changed transparency on Turkish-Q and similar layouts | zooms on every layout | — |
| **Ctrl+Shift+-** | changed transparency | sends Ctrl+_ again (readline/emacs undo) | — |
| **Selecting text** | overwrote the clipboard | fills the PRIMARY selection (middle-click pastes it); the clipboard is untouched | `copy_on_select = "clipboard"` (or `"both"`, `"off"`) |
| **Right / middle click over tmux, nvim, mc…** | always JeTTY's menu / paste | go to the program when it tracks the mouse | **Shift+right-click** opens JeTTY's menu (a selection does too) |
| **Kitty keyboard protocol** | off | on — Shift+Enter is a newline in Claude Code; nvim/fish/helix get unambiguous keys. If a program dies with the mode on, the next prompt undoes it | `kitty_keyboard = false`; palette → *Reset keyboard & mouse modes* |
| **Settings saves** | rewrote `config.toml` from scratch | edit it in place: your comments, formatting and unknown keys survive | — |

## Fixed

**Things you could hit every day**
- A hidden window could keep one CPU core at 100% (perf HUD on, hidden within
  0.7 s of the last frame).
- **Home / End did nothing** at oh-my-zsh prompts (they ignored the
  application-cursor mode the prompt turns on).
- The **block cursor hid the character under it**; the character is now drawn
  on top of the block in a contrasting color.
- **F9 hid a window that was open but behind others** — it now brings it to
  the front (and still hides a focused window on the first press).
- **Run & Notify, prompt jumps, failed-command markers and inline images
  stopped working** in a tab once its scrollback filled up (10,000 lines by
  default) — they now keep working for the tab's whole life.
- **Resizing a bash tab erased its output and scrollback** (JeTTY's own bash
  integration). Startup banners (motd, fastfetch) survive a resize too. Bash
  now reports command start, so Run & Notify gets real durations there.
- `clear` left a stale red failed-command marker or image behind.
- A typo in a theme file such as `cursor = "#aç"` crashed JeTTY with every
  tab.
- One wrong value in `config.toml` (`opacity = "0.9"`) reset **every** setting;
  now only that key falls back, with a visible notice. A broken user theme no
  longer replaces your theme choice for good.

**Found in the final review**
- Esc pressed to close JeTTY's right-click or tab menu went to the program
  (and interrupted a running Claude Code turn) — it now only closes the menu.
- Ctrl+L in a tab with a full scrollback dropped every prompt mark and image.
- nvim yanks over OSC 52 (`clipboard=unnamed,unnamedplus`) reached only the
  PRIMARY selection; both selections get them now.
- A typo in `config.toml` (or a table-style `[keys]` entry) could reset every
  setting and **remove your "Launch at login" entry** — neither can happen now.
- A program that pushed the kitty keyboard mode 4,097 times crashed JeTTY.
- Bash prompts are never erased by a resize (multi-line prompts included).

**Security**
- **Pastejacking:** pasted text containing `^C`/`^Z`/`^\` could make the shell
  run the following lines immediately. Every paste now strips control
  characters.
- JeTTY's own notices could be steered by a crafted directory name (escape
  sequences); they are neutralized now.
- An endless escape sequence could grow memory without bound; every OSC is
  capped at 1 MiB, and the cap is checked against the parser byte for byte.
- Notification bodies are markup-escaped; stacked combining marks ("Zalgo")
  are capped.

**Pictures and text**
- Sixel and Kitty images now show on the alternate screen (yazi, image.nvim,
  ranger previews) instead of being acknowledged and dropped.
- Animated images no longer pile up hundreds of hidden layers.
- Combining marks are drawn: decomposed `é`, macOS file names with ç ş ğ ö ü İ,
  ZWJ sequences.

**macOS**
- Option+key on non-US layouts typed an escape sequence instead of the
  character (Option+Q `@` on a Turkish Mac). New `macos_option_as_alt` for
  people who want Option as Meta.
- Shells start as login shells (Homebrew/rustup PATH from `~/.zprofile`).
- Launch at login works (a LaunchAgent); the global hotkey lives on the main
  thread as macOS requires.

**Detached windows** (Ctrl+Shift+D) now have everything the main window has:
search, help, the command palette, hint mode and copy mode, the Shift-drag
hint, the perf HUD, correct sizing when detached from fullscreen.

**Floods** (`cat` of a huge log, `yes`): memory stays bounded and Ctrl+C
quiets the screen in about 50 ms (it used to take seconds).

## New

- Double-click selects a word, triple-click a line; dragging past the edge
  scrolls.
- Full mouse reporting: right/middle/back/forward buttons with
  Shift/Alt/Ctrl, all encodings (SGR, UTF-8, urxvt).
- Focus reporting (nvim `FocusGained`, tmux `focus-events`).
- Drag & drop a file to paste its quoted path.
- IME composition is drawn at the cursor and the candidate window follows it.
- `--background` starts JeTTY hidden (used by "Launch at login");
  `$JETTY_CONFIG_DIR` selects another config directory.
- The UI scales cleanly at large UI fonts and on HiDPI (Retina / 200%), and
  works with proportional UI fonts.

## Faster

| Frame (CPU) | v0.25.2 | v0.26.0 |
|---|---|---|
| 240×70, typing | 4.40 ms | 0.49 ms |
| 240×70, scrolling | 4.36 ms | 0.48 ms |
| 120×40, typing | 1.06 ms | 0.26 ms |
| cursor / caret only | 0.28 ms | 0.11 ms |

- Idle is truly idle: the 100 ms background wake-up is gone.
- A keystroke no longer renders a frame before the shell's echo arrives, and
  the swapchain queues one frame instead of two.
- Opening Settings or detaching a tab no longer stalls for ~100 ms (one GPU
  device and one font database for every window).

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/bozdemir/JeTTY/main/install.sh | sh
```

Or a `.deb` / **AppImage** from the assets below (the installer verifies
`SHA256SUMS.txt`). Build from source: `cargo build --release`.
