# JeTTY v0.28.0

**The fix-and-polish release: about sixty bugs fixed, JeTTY runs without
Vulkan, F9 is faster and always takes the focus, and every frame costs less
CPU.**

Ten parallel reviews went through the whole codebase — renderer, terminal
emulation, shell, input, config, Settings, performance, selection, windows and
the v0.27 visuals. Every fix comes with a test that failed before it.

## Highlights

- **Runs without Vulkan.** On VMs, older GPUs and software rendering JeTTY now
  draws through OpenGL 3.3 / OpenGL ES 3.0 on X11 and Wayland — before, it
  opened an unpainted window. `WGPU_BACKEND=gl` forces OpenGL.
- **Faster F9, always focused.** The hotkey no longer polls 20 times a second;
  hiding takes 3 ms instead of up to 50. Under KWin, F9 could bring JeTTY to the
  front while your typing still went to the previous window — fixed.
- **Faster start, less memory on multi-GPU laptops.** JeTTY no longer loads
  Vulkan drivers for GPUs it won't use: GPU setup 74 → 20 ms, ~90 MB less
  memory, and the NVIDIA GPU is left alone.
- **Cheaper frames.** The terminal snapshot costs half as much and the tab bar
  and status bar draw in one pass.
- **Settings from the keyboard.** Tab to any control, arrows to adjust,
  Space / Enter to toggle.
- **Tabs:** drag to reorder, wheel over the bar to switch, middle-click to close.
- **`jetty --check-config`** and a reference for every key,
  [docs/configuration.md](https://github.com/bozdemir/JeTTY/blob/v0.28.0/docs/configuration.md);
  typos are reported with the closest valid spelling.

## Fixed, among others

- A crash when a program scrolled a region while you were scrolled back
  (present in v0.27.0).
- Ctrl+; on Turkish-Q (and Ctrl+# on German) sent SIGQUIT to the running
  program.
- Enter on an empty prompt after a failed command marked the prompt failed
  (powerlevel10k, bash).
- `$SHELL` inside JeTTY named the login shell instead of the one JeTTY runs.
- Changing the display scale and back shrank the window into a corner.
- A new tab from a directory on a dead network mount froze JeTTY.
- Turning CRT off didn't free its GPU memory; animated backdrops redrew on every
  keystroke; phone photos showed sideways.
- Color queries ignored colors a program had set (neovim, bat, delta picked the
  wrong background).

Full list: [CHANGELOG](https://github.com/bozdemir/JeTTY/blob/v0.28.0/CHANGELOG.md).

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/bozdemir/JeTTY/main/install.sh | sh
```

Or a `.deb` / **AppImage** from the assets below (the installer verifies
`SHA256SUMS.txt`). Build from source: `cargo build --release`.
