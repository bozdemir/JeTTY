# JeTTY v0.26.1

**F9 brings a window that sat behind others to the front — on the first press.**

v0.26.0 taught F9 to bring back a JeTTY window that is open but covered by
other windows, instead of hiding it. On KWin (KDE Plasma) the window manager's
focus-stealing prevention refused the request: the first press did nothing and
the second one hid the window. Running v0.26.0 for real under KWin 6.6 showed
it; this release fixes it, verified the same way:

| JeTTY is… | F9 |
|---|---|
| in front | hides it |
| hidden | brings it up |
| open but behind other windows | **brings it to the front** |
| minimized | restores it |

On X11 a raise the user asked for — F9, `jetty --show`, a command typed in a
detached window that acts on the main one — is now the standard EWMH
activation request a taskbar click sends, which every EWMH window manager
honors. Nothing desktop-specific; Wayland and macOS are unchanged.

## Checked in a live window

The rest of v0.26.0 was exercised in a real window as well — real zsh with
oh-my-zsh and powerlevel10k, a Turkish-Q keyboard, KWin as the window manager:
Home/End at the prompt, Shift+Enter over the kitty keyboard protocol (and a
plain Enter once a program that left the mode on has exited), Ctrl++ zoom,
the block cursor's character, double/triple-click into PRIMARY and
middle-click paste, the pastejacking guard, PageUp to the shell and
Shift+PageUp to the scrollback, right-click and Esc around mouse-tracking
programs, focus reporting, search/palette/hints/copy mode in a detached
window, every Settings tab, 0% CPU when idle (shown and hidden), and Ctrl+C
during a `yes` flood (21 ms).

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/bozdemir/JeTTY/main/install.sh | sh
```

Or a `.deb` / **AppImage** from the assets below (the installer verifies
`SHA256SUMS.txt`). Build from source: `cargo build --release`.
