# JeTTY v0.27.0

**Visuals v2 — one-click Looks, 46 themes, backdrops, cursor styles, new summon
reveals, tab styles and a rebuilt Settings window. Just as fast.**

![JeTTY in its default look: Catppuccin Mocha, a powerlevel10k prompt, tabs with activity badges and a progress bar](https://raw.githubusercontent.com/bozdemir/JeTTY/v0.27.0/assets/screenshots/hero.png)

## What's new

- **46 themes, 11 of them light** — 24 new, with exact upstream palettes, and
  a theme gallery in Settings that previews as you arrow through it.
  **Follow the system light/dark setting** (`follow_system_theme`,
  `light_theme`), and `minimum_contrast` lifts unreadable text.
- **Backdrop** — a subtle per-theme look, gradients, your own image (frosted
  if you like, no compositor needed) or a pattern: stars, aurora, grid,
  synthwave. Baked once, then a copy per frame (~0.2–0.4 ms GPU at 1440p).
- **Effects** — presets (Retro CRT, Amber, Green Phosphor, Neon, Paper,
  E-ink), phosphor colors, film grain, a bloom radius, an optional glitch on a
  failed command. The CRT pass itself is ~45% faster.
- **Cursor** — five shapes, thickness, a faint row guide, and a trail that
  smears when the cursor jumps (never while you type).
- **Summon reveals** — Pop, Glide and Fade join Phosphor, Bayer, Liquid and
  Focus; the Dropdown strip now slides in with its real edge and corners.
- **Motion** — `reduce_motion` (off / on / follow the desktop) calms every
  animation; a visual bell (flash or rim) and a glow along the window edge
  when a command fails.
- **Tabs** — five styles, per-tab colors, finished/failed/bell badges, and
  progress bars from programs that report it (OSC 9;4: Claude Code, cargo).
- **Built-in glyphs** — box drawing, blocks, Powerline separators, braille
  and sextants are drawn by JeTTY, cell-exact: no seams in powerlevel10k
  prompts, tmux borders or btop graphs (and a btop-like screen renders 2×
  faster).
- **Settings rebuilt** — every tab scrolls, sections fold, Reset tab, and
  every control is a palette search away ("bloom" → *Settings › Effects ›
  Bloom*).

## Changed by default

- **Inner padding** (8 px at the sides, 4 px top and bottom) — text no longer
  touches the window edge. `padding_x = 0` / `padding_y = 0` brings back the
  old layout.
- **Built-in glyphs** are on — `builtin_glyphs = false` goes back to the
  font's.
- Faint text blends toward the background, underlines sit at the font's
  underline position, and menus, pills and the scrollbar read on every theme.

Everything else new is off until you turn it on — or pick a Look.

## Fixed

- The default **Phosphor** reveal had played upside down since v0.1.0; it
  reveals top-down again.
- With CRT on, the Focus and Liquid reveals dropped the CRT look until they
  ended.
- The caret flash made the cursor vanish on light themes.
- Text drifted off the grid at fractional font sizes; bold box-drawing
  characters showed as empty boxes; the scrollbar was mis-sized on 2×
  displays; the launch splash covered a two-line prompt.

## Speed

Typing and scrolling frames cost the same as v0.26.1 (0.49 ms CPU at 240×70),
throughput is unchanged, and an idle JeTTY still uses 0% CPU. Effects you
don't use are never built. Measured as a round-robin of v0.26.1, nine merge
points and this release — `docs/perf-budget.md`.

Full list: [CHANGELOG](https://github.com/bozdemir/JeTTY/blob/v0.27.0/CHANGELOG.md).

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/bozdemir/JeTTY/main/install.sh | sh
```

Or a `.deb` / **AppImage** from the assets below (the installer verifies
`SHA256SUMS.txt`). Build from source: `cargo build --release`.
